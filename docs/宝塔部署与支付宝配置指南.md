## 〇、开始前你需要准备什么

| 事项 | 要求 | 说明 |
|---|---|---|
| 云服务器 | 1核2G 起，Linux（推荐 Debian/Ubuntu） | 本项目 SQLite 单文件存储，无需数据库服务器 |
| 域名 | **已完成 ICP 备案** | 国内服务器 + 支付宝回调都硬性要求备案域名 |
| 支付宝账号 | **企业支付宝** | 资金预授权、芝麻信用免押均不对个人账号开放 |
| 营业执照 | 经营范围建议含租赁相关 | 小程序类目审核、信用借还服务审核会核验资质 |

> ⚠️ 三个硬门槛先确认：**备案域名、企业主体、租赁资质**。缺任何一个，后面支付宝环节会卡住。

## 一、宝塔面板：部署后端

### 1.1 安装宝塔面板与运行环境

1. SSH 登录服务器，执行宝塔官网（bt.cn）给出的安装脚本，装好后记下面板地址和账号密码。
2. 首次进入面板，在推荐套件里**只需要安装 Nginx**（LNMP/LAMP 里的 MySQL、PHP 都不需要）。
3. 软件商店搜索安装：**Python 项目管理器**（若你的面板版本在「网站」侧栏自带「Python 项目」，用哪个都行）。

<!-- 📷 images/bt-01-panel-install.png：宝塔首次进入的推荐套件弹窗，只勾选 Nginx -->

### 1.2 拉取代码

面板左侧「文件」→ 进入 `/www/wwwroot/` → 打开终端（或 SSH）执行：

```bash
cd /www/wwwroot
git clone https://github.com/lirunzegithub/guanlan_zfb_zulin_miniprogram.git guanlan
```

拉完后确认目录结构是 `/www/wwwroot/guanlan/houdan`（后端）和 `/www/wwwroot/guanlan/qianduan`（小程序源码，服务器上用不到，给开发者工具用的）。

### 1.3 创建 Python 项目

「Python 项目管理器」→ 添加项目，按下表填（不同面板版本字段名略有差异，对号入座即可）：

| 字段 | 填什么 |
|---|---|
| 项目路径 | `/www/wwwroot/guanlan/houdan` |
| Python 版本 | 3.10 及以上（没有就先在管理器里安装一个） |
| 框架 / 启动方式 | **gunicorn** |
| 启动文件 / 模块 | `run:app`（即 `run.py` 里的 `app` 对象） |
| 端口 | `8001` |
| 是否安装依赖 | 勾选，依赖文件 `requirements.txt` |

如果你的面板要求手填启动命令，用这条（等价）：

```bash
gunicorn --workers 1 --worker-class gthread --threads 8 \
         --bind 127.0.0.1:8001 'run:app'
```

> **为什么 workers=1**：项目内置了后台定时任务（订单超时清理、租期推进）和登录防爆破计数器，
> 都是进程内实现；SQLite 也更适合单写入进程。`gthread + 8 线程`足够支撑小程序后台的并发量。
> 后续确有性能需要再评估多 worker。

首次启动成功后，项目会自动创建 `houdan/data/app.db` 并灌入种子数据。在「日志」里看到
`scheduler started` 字样即正常。

<!-- 📷 images/bt-02-python-project.png：Python 项目管理器添加项目的表单填写 -->

**如果没有 Python 项目管理器**（备选方案）：手动建虚拟环境后，用软件商店的「进程守护管理器（Supervisor）」托管同一条 gunicorn 命令：

```bash
cd /www/wwwroot/guanlan/houdan
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# Supervisor 里启动命令填：
# /www/wwwroot/guanlan/houdan/.venv/bin/gunicorn --workers 1 --worker-class gthread --threads 8 --bind 127.0.0.1:8001 run:app
# 运行目录填：/www/wwwroot/guanlan/houdan
```

### 1.4 添加站点 + HTTPS + 反向代理

1. 「网站」→ 添加站点：域名填你的备案域名（如 `zulin.example.com`），**不创建数据库、不装 PHP**。
2. 站点设置 → 「SSL」→ Let's Encrypt 一键申请证书 → 开启「强制 HTTPS」。
3. 站点设置 → 「反向代理」→ 添加反向代理：
   - 代理名称：随意（如 `houdan`）
   - 目标 URL：`http://127.0.0.1:8001`
   - 发送域名：`$host`

宝塔生成的反代配置默认带 `X-Forwarded-For` 透传，登录防爆破的 IP 识别依赖它，不要删。

<!-- 📷 images/bt-03-ssl.png：站点 SSL 页 Let's Encrypt 申请成功、强制 HTTPS 开启 -->
<!-- 📷 images/bt-04-proxy.png：反向代理配置表单，目标 URL 指向 127.0.0.1:8001 -->

4. 「安全」（以及云厂商控制台的安全组）：放行 `80`、`443`；**8001 不要对公网开放**（只走本机反代）。

### 1.5 验证部署

浏览器依次访问：

| 地址 | 预期 |
|---|---|
| `https://你的域名/` | 平台介绍页 |
| `https://你的域名/manager` | 管理后台登录页 |

登录管理后台：默认账号 `admin / admin888888`。

> ⚠️ **登录后第一件事**：「工作人员」页修改密码或新建自己的管理员账号。这是公开仓库里的演示弱口令。
> 系统自带防爆破（同账号 15 分钟内错 5 次锁 15 分钟），但弱口令仍然必须换。

<!-- 📷 images/bt-05-manager-login.png：https://域名/manager 登录页正常渲染 -->

## 二、支付宝开放平台：申请与开通

这一章是"过支付宝"的完整申请逻辑。所有操作都在 [支付宝开放平台](https://open.alipay.com)（用**企业支付宝账号**登录）。审核类步骤给出的时长是常见值，以平台实际为准。

### 2.1 入驻与创建小程序

1. 开放平台 → 完成**开发者入驻**（企业主体，一般当天通过）。
2. 控制台 → 「创建应用」→ 类型选**小程序**。填名称、简介、头像。
3. 小程序**类目**：选择与租赁匹配的类目（如"生活服务-租赁"方向），按页面提示上传营业执照等资质。类目审核不通过，后续产品签约和上架都会被卡。
4. 创建完成后，在应用详情页拿到 **APPID**（`2021` 开头的一串数字）——后面前后端都要用。

<!-- 📷 images/zfb-01-create-app.png：开放平台创建小程序应用，拿到 APPID -->

### 2.2 产品开通清单（核心）

进入你的小程序应用 → 「产品绑定 / 产品中心」，逐个开通签约。**这是整个接入的关键路径**：

| 产品 | 用途（对应本系统功能） | 说明 |
|---|---|---|
| **资金预授权（线上）** | 押金冻结 / 解冻 / 转支付扣款 | 产品码 `PRE_AUTH_ONLINE`；需企业签约，可能涉及费率协议 |
| **信用借还（芝麻信用）** | 免押金下单的"免押"能力本身 | 需芝麻侧对商家做信用评估；见 2.3 |
| **实人认证** | 下单前的实名 + 人脸核验 | `alipay.user.certify.open.*` 系列接口 |
| **小程序基础能力** | 登录授权、tradePay 等 | 创建小程序时一般自动具备 |
| **商家订单履约同步** | 订单同步到支付宝订单中心（我的-订单可见） | `alipay.merchant.order.sync`，无此产品时系统会同步失败但不影响主流程 |

> 每签约一个产品，建议回到本系统管理后台用「支付宝自检」（见 4.3）验证一次接口连通性，
> 问题早发现早处理，不要等全部签完再一起排查。

### 2.3 信用借还服务：拿 SERVICE_ID

免押能力的核心凭证。**没有它，用户在收银台看不到"芝麻免押"选项，只会降级成普通押金冻结。**

1. 开放平台 → 「信用服务管理」（入口也可能叫"芝麻信用-信用借还"）→ 创建服务。
2. 服务类目选择与你出租物品匹配的**信用预授权类目**，本系统默认 `RENT_DIGITAL`（数码其他），
   手机租赁选 `RENT_PHONE`、电脑平板选 `RENT_COMPUTER`。合法取值见
   [官方类目表](https://opendocs.alipay.com/open/10719)。
3. 按页面要求填写服务说明（押金规则、租借流程、逾期处理等），提交审核。
4. 审核通过后得到 **SERVICE_ID**（很长的一串数字）——记下来，第四章要填进后台。

<!-- 📷 images/zfb-02-service-id.png：信用服务管理里创建服务后展示的 SERVICE_ID -->

### 2.4 开发设置：回调地址与域名白名单

应用详情 → 「开发设置」，逐项填写（把 `你的域名` 替换成 1.4 配好的 HTTPS 域名）：

| 设置项 | 填什么 |
|---|---|
| 应用网关（gateway_url） | `https://你的域名/api/alipay/notify/gateway` |
| 授权回调地址 | `https://你的域名/api/alipay/oauth/callback` |
| 服务器域名白名单（httpRequest） | `https://你的域名` |
| downloadFile 合法域名 | `https://你的域名`（商品图片走它加载） |

> 业务通知地址（冻结/解冻/扣款的 notify_url）**不需要在平台配置**——本系统每次调接口时
> 动态携带，只要求你在第四章把 `notify_base` 域名配置正确。

<!-- 📷 images/zfb-03-dev-settings.png：开发设置页四个字段填写完成 -->

## 三、密钥（证书）配置

本系统使用**公钥模式**（非"公钥证书"模式），涉及 3 个 PEM 文件 + 可选的 AES 密钥。

### 3.1 生成 RSA2 密钥对

1. 下载官方[支付宝开放平台密钥工具](https://opendocs.alipay.com/common/02kipl)。
2. 选择：密钥格式 **PKCS8（Java适用）或 PKCS1 均可**（后端自动兼容转换）、密钥长度 **2048**、算法 **RSA2**。
3. 点击生成，得到**应用私钥**和**应用公钥**。私钥立即妥善保存，泄露等于资金接口失守。

<!-- 📷 images/key-01-gen.png：密钥工具生成 RSA2 密钥对界面 -->

### 3.2 上传应用公钥，换取支付宝公钥

1. 开放平台 → 应用详情 → 「开发设置」→ 「接口加签方式」→ 选择**公钥模式**。
2. 把 3.1 生成的**应用公钥**粘贴进去保存。
3. 保存后平台会展示**支付宝公钥**——复制下来，这是验签用的（注意：它和你的应用公钥是两个东西）。

<!-- 📷 images/key-02-upload.png：接口加签方式设置为公钥模式并显示支付宝公钥 -->

### 3.3 把 3 个 PEM 放进服务器

宝塔「文件」进入 `/www/wwwroot/guanlan/houdan/rsa_keys/`，参照目录里的 `.example` 示例，创建 3 个真实文件（内容为对应密钥文本，带不带 `-----BEGIN...-----` 头尾均可识别）：

| 文件名 | 内容 |
|---|---|
| `app_private_key.pem` | 你的应用私钥（3.1 生成） |
| `app_public_key.pem` | 你的应用公钥（3.1 生成） |
| `alipay_public_key.pem` | 支付宝公钥（3.2 平台返回） |

> 这 3 个文件已被 `.gitignore` 排除，不会随代码提交。**不要**把它们复制到仓库以外的公开位置。

### 3.4 （可选）接口内容加密 AES

若在开放平台开启了「接口内容加密」（涉及身份证号等敏感字段的接口建议开启）：

1. 平台「接口内容加密方式」里生成 AES 密钥（base64 一串）。
2. 编辑 `houdan/app/config.py`，把密钥填到 `AES_ENCRYPT_KEY = ""` 的引号里。
3. 未开启则保持留空，系统自动走明文（RSA2 签名不受影响）。

## 四、系统对接配置与自检

### 4.1 管理后台「设置」页（推荐方式，改完即生效）

用 admin 账号登录 `https://你的域名/manager` → 「系统设置」，填写：

| 设置项 | 填什么 | 不填的后果 |
|---|---|---|
| 公网 HTTPS 域名（notify_base） | `https://你的域名` | 支付宝回调打不进来、商品图片不显示 |
| 支付宝 APPID | 2.1 拿到的 APPID | 所有支付宝接口不可用 |
| 信用借还 SERVICE_ID | 2.3 拿到的 SERVICE_ID | 免押降级为普通押金冻结 |
| 信用借还业务类目 | 默认 `RENT_DIGITAL`，按 2.3 所选类目改 | 类目不符会导致免押页不出现 |
| 客服电话 / 公司名称 / LOGO | 你的真实信息 | 小程序展示占位内容 |
| 顺丰丰桥 顾客编码 / 校验码 | 丰桥开放平台申请后获得 | 见下方说明，**不填不影响下单收款** |

<!-- 📷 images/cfg-01-settings.png：管理后台设置页各支付宝字段填写完成 -->

**关于顺丰丰桥（选填）**

填了之后，顺丰单的「待收货 → 租赁中」由**真实签收轨迹**驱动：包裹第 1 天就签收了，订单当天就转「租赁中」，
且归还日按真实签收相应提前（用机天数不变、金额不变、已冻结的押金不动）。

不填（或查询失败、非顺丰单）时，退回到原本的定时器逻辑——**发货时间 + 物流免租期**到点自动转「租赁中」。
这条保底始终有效，所以顺丰没对接也不会有订单卡在「待收货」。

注意两点：

1. 要填的是**丰桥「顾客编码」（partnerID）**，不是月结卡号，两者不是一回事；
2. 沙箱与生产凭据不通用，用沙箱联调完记得把「顺丰环境」切回生产。

### 4.2 config.py 里的少量硬编码项

`houdan/app/config.py` 只剩两处可能要动：

- `ENV = "prod"`：默认生产环境。要用沙箱联调改成 `"sandbox"`（沙箱的 APPID/密钥也要换成沙箱版）。
- `AES_ENCRYPT_KEY`：见 3.4。

改完后在宝塔 Python 项目管理器里**重启项目**（改 `config.py`、更新代码后都需要重启；改后台「设置」页不需要）。

### 4.3 一键自检（强烈建议每次配置变更后跑一遍）

管理后台「系统设置」页顶部 → 「支付宝自检」→ 勾选「联网验证」→ 运行。

自检会检查：密钥文件是否存在且格式正确、APPID 是否配置、签名往返是否自洽、（联网时）网关握手与验签是否通过。全绿即对接就绪；有红项按提示定位到上面第二、三章对应步骤。

## 七、常见问题排查

**Q1：支付宝回调收不到（订单一直停在"待免押"，但用户实际付款成功了）**
依次检查：后台设置 notify_base 是否为真实 HTTPS 域名 → 域名证书是否有效（浏览器直接访问无告警）→ 宝塔「安全」和云安全组 443 是否放行。定位工具：后台「回调日志」页，有记录说明打进来了，看 verify/biz 列；一条都没有说明网络层没通。
另外系统对此有兜底：用户重新进入订单详情页会主动向支付宝对账并推进订单状态,回调丢失不会造成资金悬挂。

**Q2：收银台里看不到"芝麻免押"，只有普通支付方式**
按概率排序：SERVICE_ID 未配置或服务未过审（后台设置页检查）→ 业务类目与信用服务不匹配 → 用户本人芝麻分不够格（这是支付宝端正常分流，系统会自动落到押金冻结，不是故障）。

**Q3：小程序里商品图片不显示**
notify_base 未配置（图片绝对地址拼不出来），或开放平台 downloadFile 合法域名没加你的域名。

**Q4：IDE 里点免押/支付报错**
`my.tradePay` 仅支持真机，用"真机预览"扫码测试。

**Q5：管理后台提示"失败次数过多，账号已锁定"**
防爆破机制：同账号 15 分钟内错 5 次锁 15 分钟。等待解锁，或重启后端进程立即清零计数（计数在内存中）。

**Q6：更新代码后功能没变化**
`git pull` 之后必须在 Python 项目管理器里重启项目；浏览器端后台页面再强制刷新（Ctrl+Shift+R）。

**Q7：想清空演示数据重新开始**
停止项目 → 删除 `houdan/data/app.db` → 启动项目（自动重建并灌入种子数据）。⚠️ 会连同真实订单一起清空，仅限上线前使用。
